# Authentication

All API endpoints are free to use, with a limit of 5 API requests per hour. For 1,000 requests per hour, subscribe to [Animechan Premium](/pricing) ($5/month) and you'll receive an API key by email. Send it in the `x-api-key` header to access the API with the higher rate limit.

Here is how to authenticate using a secret API key:

```js
const response = fetch(`${BASE_URL}/quotes/random?anime=ReLIFE`, {
		headers: {
				'x-api-key': 'YOUR_API_KEY',
		},
});
const quote = await response.json()
```
